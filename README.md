# 匿名评分榜 H5 网页版

这是一个可直接用手机浏览器打开的静态网页 Demo。

## 使用方式

1. 解压本文件夹
2. 直接打开 `index.html` 可以本地预览
3. 上传到 Netlify / Vercel / GitHub Pages / 宝塔服务器 / 阿里云 OSS 等静态托管平台
4. 获得公网网址后，用任意二维码生成器生成二维码
5. 用户扫码即可打开

## 当前版本功能

- 首页评分榜
- 计算机 / 商科分类
- 人名搜索
- 0-10 分匿名评分
- 自动计算平均分
- 同一浏览器用户重复评分时自动修改原评分
- 管理入口可添加评分对象

## 重要说明

当前 Demo 使用浏览器 localStorage 保存数据，所以不同用户之间的数据不会同步。
如果要正式上线，需要接入后端数据库，例如：

- Supabase
- Firebase
- 微信云开发
- MySQL + Node.js
- PHP + MySQL

正式版建议增加：

- 用户 openid / 手机号 / 设备指纹防刷分
- 后台管理登录
- 举报功能
- 敏感词过滤
- 数据库实时统计
- 人物审核机制
